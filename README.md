# 📦 Sistema de Controle de Estoque em Java

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação, vetores, estruturas de repetição, condicionais e manipulação de dados em memória.

## 🚀 Funcionalidades

- Cadastro de produtos
- Entrada de estoque
- Saída de estoque
- Consulta de produtos
- Alerta de estoque baixo
- Controle de categorias
- Validação de dados
- Busca de produtos por nome

## 🛠️ Tecnologias Utilizadas

- Java
- IntelliJ IDEA
- Scanner para entrada de dados
- Vetores (Arrays)

## 📋 Estrutura dos Dados

Cada produto possui:

- Nome
- Preço
- Quantidade em estoque
- Categoria

Os dados são armazenados em vetores paralelos durante a execução do programa.

## 📚 Conceitos Praticados

- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`for`)
- Métodos
- Vetores
- Validação de entrada
- Busca de dados
- Manipulação de estoque
- Organização de código

## 🎯 Objetivo

Este projeto foi desenvolvido para consolidar conhecimentos fundamentais de Java e lógica de programação, simulando operações básicas de um sistema de gerenciamento de estoque.
